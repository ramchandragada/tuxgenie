Why Aspera Hub

Keep your daily apps warm. Leave the rest cold.

One window for the web apps you live in — without a pile of browser tabs or a memory-hungry suite.

🔥 Warm apps

Mark the apps you use all day to “keep warm” — up to 5 stay loaded for instant switching. No cold-start wait when you jump to WhatsApp or Gmail.

🧊 Cold on demand

Everything else loads only when you click it, and can hibernate after it’s been idle — so the apps you rarely open aren’t quietly using resources.

🐧 Free & Linux-first

100% free, forever — no trials, no ads, no account. MIT-licensed and built for Debian, Ubuntu and Linux Mint.

Features

A real desktop shell — not just tabs

The polish you expect from a native app, around the web apps you already use.

Separate logins

Named profiles keep sessions isolated, so several WhatsApp or Gmail accounts never share cookies.

Unread badges

Per-app counts, a global bell, and an optional tray badge — see what needs you at a glance.

Focus & mute

Silence notifications or clear badges with a shortcut when you need to concentrate.

Quick switch & search

Jump to any app with Ctrl+1…9 or Ctrl+/, and find-in-page with Ctrl+F.

Optional password lock

Lock the whole workspace with a password, and auto-lock when your PC goes idle or sleeps.

Downloads & tray

Choose a downloads folder, open files when they finish, and keep Hub in the tray or close-to-tray.

Themes

System, light, dark, darkest, glossy or mint — make the shell match your desktop.

Auto-update

Updates come straight from GitHub Releases and are checked with SHA-256, so upgrades are safe.

Keyboard-driven

Reorder tabs, reload an app, toggle focus, hibernate the background, or lock — all from the keyboard.

Install

Up and running in a minute

Download the .deb, install it, and launch Aspera Hub from your app menu.

DebianUbuntuLinux Mintamd64
# Recommended — double-click the .deb, or from a terminal:
sudo apt install ./asperadock_<version>_amd64.deb

# Or with dpkg, then fix any missing dependencies:
sudo dpkg -i asperadock_*_amd64.deb
sudo apt-get install -f

The package is named asperadock (kept stable so updates carry over) — the launcher and About screen show Aspera Hub. Updates are delivered in-app from GitHub Releases.

FAQ

Good to know

Is it really free?

Yes — free, forever. No subscription, no trial wall, no ads.

Which Linux distros are supported?

Debian, Ubuntu and Linux Mint (amd64). Other Debian-based distributions usually work too.

How is it different from Rambox or a browser?

A warm/cold design that keeps your daily apps instant while letting the rest sleep — typically lighter on RAM, and it’s free and Linux-first. You also get a real desktop shell: badges, tray, mute, focus, lock, downloads and isolated logins.

Where do my logins live?

On your machine, under your own user profile. Aspera Hub is a desktop app — there’s no cloud account and no server in the middle.

Will more apps be added?

Yes — the catalog can grow. Today it covers messaging, mail and Zoho, plus any custom HTTPS URL you add yourself.
