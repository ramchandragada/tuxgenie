The idea

Warm where it counts. Cold everywhere else.

A browser keeps every tab alive; a big suite keeps everything running. Aspera Hub does neither — you decide what stays hot.

Warm apps

Mark the handful you use all day to keep warm — up to 5 stay fully loaded, so switching to WhatsApp or Gmail is instant, with no cold-start spinner.

Hard cap: 5 warm views · instant switch

Cold on demand

Everything else loads only when you click it, and can hibernate after it's been idle — so the apps you rarely open aren't quietly holding memory.

Sensible on a ~16 GB laptop

Features

A real desktop shell — not just tabs

The polish of a native app, wrapped around the web apps you already live in.

Separate logins

Named profiles keep sessions isolated, so several WhatsApp or Gmail accounts never share cookies.

Unread badges

Per-app counts, a global bell, and an optional tray badge — see what needs you at a glance.

Focus & mute

Silence notifications or clear every badge with a shortcut when you need to concentrate.

Jump anywhere

Switch apps with Ctrl+1…9, quick-search with Ctrl+/, find in page with Ctrl+F.

Password lock

Lock the whole workspace behind a password, and auto-lock when your PC goes idle or sleeps.

Downloads & tray

Pick a downloads folder, open files when they finish, and keep Hub in the tray or close-to-tray.

Themes

System, light, dark, darkest, glossy or mint — make the shell match your desktop.

Safe auto-update

Updates come from GitHub Releases and are verified with SHA-256 before they're applied.

Keyboard-driven

Reorder tabs, reload an app, toggle focus, hibernate the background, or lock — all from the keyboard.

Install

Running in about a minute

Download the .deb, install it, and launch Aspera Hub from your app menu.

DebianUbuntuLinux Mintamd64
bash
# Recommended — or just double-click the downloaded .deb
sudo apt install ./asperadock_<version>_amd64.deb

# Or with dpkg, then pull in any missing dependencies
sudo dpkg -i asperadock_*_amd64.deb
sudo apt-get install -f

The package is named asperadock (kept stable so your logins survive updates) — the launcher and About screen show Aspera Hub. After that, updates arrive in-app from GitHub Releases.

FAQ

Good to know

Is it really free?
Yes — free, forever. No subscription, no trial wall, no ads.
Which Linux distros are supported?
Debian, Ubuntu and Linux Mint (amd64). Other Debian-based distributions usually work too.
How is it different from Rambox or a browser?
The warm/cold design keeps your daily apps instant while letting the rest sleep — typically lighter on RAM — and it's free and Linux-first. You also get a real desktop shell: badges, tray, mute, focus, lock, downloads and isolated logins.
Where do my logins live?
On your machine, under your own user profile. Aspera Hub is a desktop app — there's no cloud account and no server in the middle.
Will more apps be added?
Yes — the catalog can grow. Today it covers messaging, mail and Zoho, plus any custom HTTPS URL you add yourself.
