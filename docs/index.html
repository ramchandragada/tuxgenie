Common questions

Everything you need to know before installing.

Your API key is stored locally in ~/.config/tuxgenie/config.json with owner-only permissions (chmod 600) and never leaves your machine. TuxGenie has no backend and collects zero telemetry — nothing is sent anywhere unless you run an AI task, and then only your chosen provider (Anthropic or Google) sees it, never us. Your sudo password is held in memory for the session only — never saved, never sent. Full details on our Privacy & Transparency page.

All three work great. You have two free options — Google Gemini and Groq (fast Llama models) — both no credit card, perfect for everyday use. Prefer top quality or a confidential machine? Use Claude — Anthropic does not train on API data. One honest note: free tiers (Gemini, Groq) may use your prompts to improve their products, so pick Claude for sensitive systems. We tell you this at the point you choose, too. Bonus: if you add keys for both free providers, TuxGenie can auto-switch between them when one hits its rate limit — so you're never stuck (and it never falls back to paid Claude without asking). See Privacy & Transparency.

It can be completely free. Pick a free tier on first launch — Google Gemini or Groq — no credit card, nothing to pay. Prefer top quality? Use Claude and you pay Anthropic only for what it uses — typically ~$0.01 per session ($5 lasts months). Either way, simple commands (ls, apt, systemctl…) bypass the AI entirely and cost nothing.

Yes, safely. Read-only checks run on their own, but every command that changes your system is shown and asks for your approval first — [y / n / abort]. Genuinely destructive commands (rm -rf /, disk wipes, fork bombs) are hard-blocked by an argv-aware filter that catches them even when disguised or reordered. Press Ctrl-C anytime, and roll back any session with option [16].

Common commands (apt, systemctl, ls, grep, etc.) run offline instantly — TuxGenie only calls the AI for complex diagnostics and fixes. So basic usage works without internet. Full AI-powered fixes need a connection to reach your chosen AI provider (Gemini, Groq or Claude).

Any distro running Python 3.8+. Full testing on Ubuntu, Debian, Fedora, Arch, Mint, Pop!_OS, Kali, openSUSE, Raspberry Pi OS, CentOS, and Rocky Linux. The .deb package installs on Debian/Ubuntu-based systems; pip installs everywhere else.

TuxGenie knows your exact system — kernel version, installed packages, running services, disk usage — and acts on it directly. It runs commands, verifies they worked, retries on failure, rolls back changes, and remembers past fixes across sessions. ChatGPT just gives text suggestions.
